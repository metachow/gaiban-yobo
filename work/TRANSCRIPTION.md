# 外蕃容貌圖画 録文規則（説明頁）

原書：田川春道撰・倉田東岳画『外蕃容貌圖画』安政2年(1855)，筑波大学附属図書館蔵本（乾坤2冊）。
本文は手書き版下の楷書，漢字片仮名交じり，振り仮名（片仮名）付き。無辺無界，行数は頁ごとに異なる。

## ファイル

- 1 頁 = 1 ファイル：`text/qian/qNNNL.txt`（乾）・`text/kun/kNNNL.txt`（坤）。NNN = スキャン番号，L = 見開きの左半分（説明文の頁）。
- **1 行 = 原本の 1 列**（右から左の順）。列の切れ目は原本どおり。行の途中で切ったり 2 列を 1 行にまとめたりしない。
- `#` で始まる行は注記。1 行目に `# 乾 scan 018 L: 暹羅. 7 columns.` の形で頁・国名・列数を書き，読めない・自信のない箇所は 2 行目以降に `# ? …` で列挙する。原本の誤り（衍字・脱字）は `# 校: …` で記録し，本文は原本どおりに写す。

## 記法

| 記法 | 意味 | 例 |
|---|---|---|
| `漢字《ヨミ》` | 振り仮名。直前の連続する漢字（振り仮名がまだ付いていないもの）全体が親字 | `朝鮮《テウセン》` |
| `｜` | 親字の始まりを明示（直前に別の漢字があって，一部だけに振り仮名がある場合） | `大明一｜統《トウ》` |
| `〔右|左〕` | 割注（二行の小字注）。右半行・左半行を `|` で区切る。割注内でも振り仮名・圏点可 | `〔馬韓《バカン》。辰韓《シンカン》。|弁韓《ベンカン》。ト分テ〕` |
| `。` `、` | 字の右下の圏点・読点（原本にあるときだけ） | `元。明。清。` |
| `　`（全角空白） | 空きのます | |
| `^N` | 行頭：その列が N 字分下がって始まる | `^2又…` |

- 振り仮名は**それが付いている字**に付ける。熟語全体に振ってあれば熟語に，1 字だけなら `｜` を使ってその字だけに。
- 振り仮名がない字には何も付けない。原本にない振り仮名を補わない。

## 字体

- 漢字は**原本の字形どおり**に入力する（Unicode にある字に限る）。国/國，来/來，号/號，亜，攺，叓（＝事）なども書かれたとおり。統一は後で `text/variants.tsv` で一括して行う（自分で直さない）。
- 「事」の略体「叓」，「改」の異体「攺」は既に表にある。ほかに Unicode の異体字を見つけたら書かれたとおり入れ，`# 異体: X` と注記する。
- Unicode にない字形は最も近い字を入れ `# ? 字形: …` と注記。まったく読めない字は `□`。
- 片仮名の振り仮名：濁点・半濁点は見えるとおり（不明なら注記）。原本で「ネ」に「子」を使う箇所は **ネ** と入力（例 `熱《ネツ》`）。踊り字 `ヽ` `ヾ` `ゝ` は書かれたとおり。
- 句読点は原本にある圏点（。）・読点（、）だけ。現代の句読点は加えない。

## 読み方の原則

- **字形を第一に，文意は補助**（以字形為主，文意為輔）。意味から推して字を「直す」ことは絶対にしない。迷ったら見えるとおりに入れ，注記する。
- 振り仮名は小さく薄いことが多い：必ず拡大して 1 字ずつ読む。
- 既に完成している頁（`text/qian/q007L.txt`〜`q017L.txt`）を見本として形式・慣用を合わせること（例：「北極地ヲ出ル叓…度ニ至ル」）。

## 道具（プロジェクト直下で実行）

- 読む画像：`work/cols/<key>_c1-3_top.jpg`, `_c1-3_bot.jpg`, `_c4-6_top.jpg` …（3 列ずつ，上半分・下半分。上端の赤い数字が列番号）。全体：`work/pages/<scan>.jpg`。さらに拡大したいときは Python で `scans/tsukuba/<scan>.png`（5616×3744）から切り出してよい（出力は `work/zoom/` に）。
- 確認：`python -I -X utf8 tools/check_page.py <key>` → `work/check/<key>.jpg`（左：原本，右：組版）。各頁を書き終えたら必ず実行し，列数・各列の字数・振り仮名の位置を原本と見比べる。`runs over` の警告は 1.10 倍以内なら無視してよい（自動で詰める）。エラーが出たら記法を直す。
- 他人の担当ファイルは編集しない。`tools/` のスクリプトも変更しない（問題があれば報告）。
