# 振り仮名・待定条目の校正（作業説明）

プロジェクト：本リポジトリ（『外蕃容貌圖画』安政2年刊の竖排仿刻本）。
録文の規則は `work/TRANSCRIPTION.md`（必読）。録文は `text/qian/*.txt`・`text/kun/*.txt`（1 行 = 原本 1 列，右から左）。
本文の漢字はすでに KuroNet との機械照合を済ませてある。今回の校正範囲は次の 2 つだけ：

1. **振り仮名**：担当頁のすべての振り仮名を原本と照合する。
2. **待定条目**：担当頁の録文ファイルにある `# ? …` の注記を 1 件ずつ原本で確かめ，結論を出す。

本文の漢字・圏点の全面的な見直しは今回は行わない（作業中に明らかな誤りに気づいたら報告してよい）。

## 資料

- `work/ruby/<key>.jpg`：その頁の振り仮名を 1 つずつ切り出した一覧。各タイルの左＝原本（親字の上下 1 字を含む），右＝録文の親字（黒）と振り仮名（青）。タイル番号 `#n` と列番号つき。対応表は `work/ruby/list.tsv`（id, key, col, base, ruby, box）。
- `work/ruby/labels.jpg`：図版頁の国名ラベル（`text/labels.yaml`）の振り仮名。
- **注意**：タイルの切り出し位置は KuroNet の文字枠から自動で決めている。番号に `≈` がつくタイル，割注の中のタイルは位置がずれて別の字を写していることがある。親字がタイルに見えないときは必ず列の拡大図で確かめること。
- 列の拡大図：`work/cols/<key>_c1-3_top.jpg` など（既存，やや縮小）。全解像度が要るときは
  `python -I tools/zoom_cols.py qian_010 L work/zoom/q010L` → `work/zoom/q010L_c1-3_top.jpg` …（列番号は上端に赤字）。
  坤は `kun_NNN`。画像全体は `scans/tsukuba/{qian,kun}_NNN.png`（5616×3744，見開き，説明文は左半分）。
- 画像は Read で見る。必要なら Python（PIL）で任意の範囲を切り出して拡大してよい（`python -I -X utf8` で実行，作業用画像は `work/review/tmp/` に置く）。

## 振り仮名の読み方

- **字形を第一に**。意味や現代の読みから推して直さない。原本が当時の慣用（歴史的仮名遣い，「テウセン」のような字音仮名遣い）ならそのまま。
- 濁点・半濁点は特に注意して拡大して見る（「ポ/ホ」「ジ/シ」）。見えないものは付けない；判断できなければ「不明」と書く。
- 原本の「子」形の「ネ」は「ネ」，「井」形は「ヰ」。踊り字（ヽヾ）は書かれたとおり。
- 振り仮名がどの字にかかっているか（熟語全体か 1 字だけか）も確かめる。録文の親字の範囲が違えば報告する（例：`大明一統《トウ》` → `大明一｜統《トウ》`）。
- 原本にあるのに録文にない振り仮名，録文にあるのに原本にない振り仮名も報告する。

## 報告（自分の担当ファイルにだけ書く。`text/` のファイルは編集しない）

`work/review/ruby_<担当>.tsv`（UTF-8，タブ区切り，見出し行つき）：

```
key	col	tile	ours	proposed	certainty	comment
q010L	3	#422	釜山浦《フサンポ》	釜山浦《フサンホ》	推定	ポの半濁点が見えない（全解像度で確認）
```

- **食い違いがあるものだけ**書く（一致したものは書かない）。`certainty` は「確実」「推定」「不明」のいずれか。
- `ours`・`proposed` は録文の記法で書く（親字《ヨミ》，必要なら ｜）。

`work/review/q_<担当>.tsv`：担当頁の `# ?` 注記すべてについて 1 行ずつ。

```
key	note	verdict	proposed	comment
q010L	繼 ruby ツヾ	現状維持		ツヾ明瞭
q010L	鴨 ruby ヲウ	修正	鴨《アフ》	…
```

- `verdict` は「現状維持」（録文どおりでよい：注記を消してよい）・「修正」（`proposed` に正しい録文）・「未決」（どうしても決まらない：校記に残す。理由を comment に）。

最後に，振り仮名をいくつ見たか，食い違い何件，待定何件（現状維持／修正／未決の内訳）を短く報告すること。
